# REGIONALE EXPRESS VOYAGES SARL ERP

## 📖 Description
ERP complet et application métier PWA (Progressive Web App) conçu sur mesure pour **REGIONALE EXPRESS VOYAGES SARL**. Ce logiciel gère l'ensemble des opérations financières et logistiques (Dépenses, Recettes, Versements bancaires, Synthèses), tout en garantissant un mode Offline-First.

## 🚀 Fonctionnalités
- Gestion des dépenses et des dettes fournisseurs
- Suivi des recettes journalières
- Suivi des versements bancaires et objectifs d'agence
- Mode Offline-First complet avec Dexie.js (Synchronisation en arrière-plan)
- Sécurité basée sur les rôles (RBAC : PDG, DG, Agent)
- Notifications Push Firebase
- Tableau de bord décisionnel PDG et DG
- Chatbot IA métier intégré

## 🏗 Architecture
Ce projet s'appuie sur une stack Next.js 14, Supabase (PostgreSQL), Prisma ORM, et TailwindCSS. Voir ARCHITECTURE.md pour plus de détails.
