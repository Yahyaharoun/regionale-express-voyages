# Roadmap 🗺️

Vision long terme du SaaS Regional Express.

### Phase 1 : Bêta (Complétée) ✅
- Architecture de base Next.js 15
- Intégration Prisma & PostgreSQL
- Maquettes fonctionnelles

### Phase 2 : Industrialisation (Actuelle) ✅
- [x] Refonte UX Apple/Linear (Skeletons, animations fluides).
- [x] SRE & DevOps (Sentry, GitHub Actions, Docker).
- [x] QA et Test Coverage (> 90%).
- [x] Pentest Sécurité (RLS, IDOR, Zod).

### Phase 3 : Déploiement Afrique (T4 2026) 🚀
- [ ] Optimisation agressive du mode Offline (Delta Sync complet via Dexie pour tout le catalogue d'opérations).
- [ ] Installation de l'application en tant que PWA native (Mobile et Desktop) avec Push Notifications.
- [ ] Support multilingue (i18n) complet.
- [ ] Outils analytiques locaux pour le suivi hors connexion.

### Phase 4 : AI & Automatisations (2027) 🤖
- [ ] Copilot "Regional Express AI" complètement fonctionnel pour générer des rapports comptables via LLM.
- [ ] Détection de fraude avancée.
